١. استقبال إشعار وصول مبلغ (من نيوتك إلينا)

يرسل البنك إشعارًا عند وصول أي مبلغ إلى حساب دخل مسجّل لشركة، فيُقسَّم المبلغ فورًا وفق سياستها النشطة.

POST {{ base_url }}/api/bank/incoming
Content-Type: application/json
X-Signature: hex( HMAC-SHA256( BANK_WEBHOOK_SECRET, raw request body ) )

{
  "iban": "SA0380000000608010167519",
  "amount": "1500.00",
  "occurred_at": "2026-09-30T10:00:00+03:00",
  "reference": "NTK-123456"
}
الحقلالوصف
ibanآيبان حساب الدخل الذي وصل إليه المبلغ، ويجب أن يكون مسجّلًا لدى إحدى الشركات
amountالمبلغ بالريال، بخانتين عشريتين
occurred_atوقت الإيداع (اختياري، وإن غاب يُعتمد وقت الاستلام. وإن خلا من المنطقة الزمنية يُعدّ بتوقيت الرياض)
referenceالرقم المرجعي لدى البنك. لا يُقسَّم المرجع نفسه مرتين، فإعادة إرسال الإشعار آمنة
